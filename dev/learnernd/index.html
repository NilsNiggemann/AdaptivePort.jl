LearnerND

LearnerND samples a function $f: \mathbb{R}^N \to \mathbb{R}^M$ on a box, with scalar values or vdim = M components (see Vector-valued functions). Points are NTuple{N}.

using AdaptivePort

f(x, y, z) = tanh(30 * (sqrt(x^2 + y^2 + z^2) - 0.6))   # a thin spherical shell
learner = LearnerND(f; bounds=((-1, 1), (-1, 1), (-1, 1)))

while npoints(learner) < 300
    for p in ask(learner, 6)
        tell!(learner, p, f(p...))
    end
end

data = result(learner)        # (points, values) in tell order
cells = simplices(learner)    # index tuples of length N + 1 into data.points

examples/learnernd.jl is a longer version, including a vector-valued function.

Algorithm

The evaluated points are kept in an incrementally updated Delaunay triangulation (AdaptivePort.TriangulationND): a new point deletes the simplices whose circumsphere contains it and fills the hole with new ones. The Delaunay criterion is evaluated in coordinates scaled by the box widths, so a box that is not a cube is treated as the unit cube.

Each simplex has a loss. The default is the volume of the simplex in the joint space of inputs and outputs (default_loss_nd): large simplices, and simplices on which $f$ changes a lot, have a large loss. Coordinates are scaled to the unit cube and the values by their total range (over all components), so the loss does not depend on units. All losses are recomputed when the range has grown by more than 10 %. ask splits the simplex with the largest loss at its centre, or at the midpoint of its longest edge if the circumcentre lies outside it.

The first points are the corners of the box, in lexicographic order. While there is no triangulation yet (fewer than $N + 1$ points not in one hyperplane) a seeded random point is asked.

A pending point subdivides the simplex it lies in, in a small sub-triangulation whose parts share the parent's loss by volume. Repeated ask calls therefore spread out instead of returning one point again and again. loss(learner) is the largest simplex loss, Inf until all corners are told; loss(learner; real = false) lets a simplex with pending points count as its largest sub-simplex.

Limits

The triangulation locates points by a linear scan and scans the hull, so cost grows quickly with the dimension (single-threaded, measured):

$N$pointsasktell!
210000.07 ms0.03 ms
315000.12 ms0.45 ms
46000.55 ms5.2 ms

\[N = 5\]

is practical for a few hundred points (tell! at 300 points takes about 54 ms), $N \ge 6$ is not (about 0.9 s per tell! at 150 points). Differences to upstream are listed under Deviations.

API

AdaptivePort.LearnerND — Type
LearnerND{N, T, V, S, F, L}

Adaptive sampler of a function f(x1, ..., xN) on the box bounds, with scalar values (V = T) or vector values (V = NTuple{M, T}), driven by ask and tell!.

The evaluated points are triangulated by an own incremental Delaunay triangulation (TriangulationND); every simplex gets a loss, and ask splits the simplex with the highest loss. Pending points subdivide their simplex in a sub-triangulation whose parts share the parent's loss by volume, so repeated ask calls spread out.

Fields: f (stored for runners, never called by the learner), bounds, loss_per_simplex, points/values/index (evaluations in tell order and point to position), pending, tri (nothing until N + 1 points not in one hyperplane exist), losses (simplex to loss), subtriangulations and pending_to_simplex (pending points), and queue (simplices sorted by priority; entries of deleted simplices are skipped when popped).

Invariants:

  • index[points[i]] == i, points are distinct and inside the closed box; pending is disjoint from points.
  • Vertex i of tri is points[i]; losses has one entry per simplex of tri.

Coordinates are scaled to the unit cube by the box widths and values by their range (all components together) before they enter a loss, as upstream. Construct with LearnerND(f; bounds, loss_per_simplex, vdim).

AdaptivePort.default_loss_nd — Function
default_loss_nd(simplex, values, value_scale)

Loss of upstream's LearnerND default: the volume of the simplex embedded in input plus output space, i.e. of the simplex with vertices (x..., y...).

This is large for large simplices and for simplices on which the function changes a lot (a steep part of the graph has a large area), so it refines where the function varies without neglecting flat regions. Coordinates are scaled to the unit box and values to unit range by the learner, so the loss does not depend on the units of f or the box.

Arguments

  • simplex: Vector of N + 1 scaled points, NTuple{N} each.
  • values: Vector of the scaled values of the vertices (numbers, or tuples for vector output).
  • value_scale: the factor that scaled the values; unused here.

Returns

  • The loss, a nonnegative number.

See Also

  • uniform_loss_nd, std_loss_nd, LearnerND

AdaptivePort.std_loss_nd — Function
std_loss_nd(simplex, values, value_scale)

Loss r * vol^(1 / N) + vol with vol the simplex volume and r the Euclidean norm of the per-component standard deviation (population, over the vertices) of the scaled values (upstream std_loss).

AdaptivePort.simplices — Function
simplices(learner::LearnerND)

Simplices of the Delaunay triangulation of the evaluated points, as sorted index tuples into result(learner).points. Empty while fewer than N + 1 points not in one hyperplane exist.

The analogue of triangles for Learner2D. It is the incrementally maintained triangulation the learner samples from (Delaunay in coordinates scaled by the box widths), so it differs from a Delaunay triangulation of the raw points when the box is not a cube, and from scipy.spatial.Delaunay where points are cospherical.

Internals

AdaptivePort.TriangulationND — Type
TriangulationND{N, T, S}

Delaunay triangulation of points in N dimensions, built incrementally by the Bowyer-Watson algorithm; a port of upstream's Triangulation. Unexported.

Fields: vertices (the points, NTuple{N, T}), simplices (the simplices, each a sorted S = NTuple{N + 1, Int} of indices into vertices) and vertex_to_simplices (for every vertex the simplices containing it).

Invariants (checked by the tests after every insertion):

  • Every simplex is listed at each of its vertices and nowhere else.
  • A face (N vertices) belongs to at most two simplices; faces with one simplex form the hull.
  • The simplices have disjoint interiors and, up to the tolerances below, empty circumspheres.

Vertices of the input that are not (yet) part of a simplex have an empty vertex_to_simplices entry. Construct with TriangulationND(points) and extend with add_point!.

Deviations from upstream: dimension 1 is supported; the initial triangulation of more than N + 1 points starts from one non-degenerate simplex and inserts the others (upstream calls scipy.spatial.Delaunay); the rank test uses a relative tolerance of 1e-10.

AdaptivePort.add_point! — Function
add_point!(tri::TriangulationND, point; simplex = nothing, transform = nothing)

Insert point into tri (Bowyer-Watson inside the hull, hull extension plus Bowyer-Watson outside) and return (deleted, added), the sets of simplices removed and created. The new vertex gets the next index.

Keyword Arguments

  • simplex: a simplex containing point; saves the O(number of simplices) point location.
  • transform: N x N matrix applied to the vertices (as row vectors) when testing circumspheres, so that Delaunay's criterion holds in the transformed (for example scaled) space.

Throws ArgumentError, leaving tri unchanged, if point is already a vertex or simplex does not contain it.

AdaptivePort.circumsphere — Function
circumsphere(pts)

Centre (NTuple) and radius of the sphere through the N + 1 points pts in N dimensions. Singular input (a flat simplex) throws LinearAlgebra.SingularException or returns non-finite numbers.

Solves 2 (p_i - p_1) ⋅ (c - p_1) = |p_i - p_1|^2 for the centre c; upstream uses closed-form determinants for N = 2, 3 and a Cayley-Menger-like determinant otherwise.

source
AdaptivePort.simplex_volume_in_embedding — Function
simplex_volume_in_embedding(vertices)

Volume of the simplex spanned by vertices (a Vector of k + 1 points of NTuple{D}, k <= D), also when k < D (for example the area of a triangle in 3D). Equals sqrt(det(V' * V)) / k! for the matrix V of edge vectors.

Upstream uses Heron's formula (D = 2) or the Cayley-Menger determinant; the Gram determinant gives the same value. A slightly negative squared volume from rounding is clamped to zero (upstream raises beyond -1e-15).

source
AdaptivePort.choose_point_in_simplex — Function
choose_point_in_simplex(simplex, widths)

New point inside the simplex (N + 1 points of NTuple{N}): its centre if the circumcentre lies inside it in the box-scaled coordinates (x / widths), otherwise the midpoint of its longest edge there (upstream choose_point_in_simplex). The result is in the original coordinates.
