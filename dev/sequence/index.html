SequenceLearner

SequenceLearner evaluates a function on a fixed list of inputs. It is a plain map that runs through the runners: parallel, cancellable, with the same interface as the adaptive learners. The points are (index, element) with a 1-based index.

using AdaptivePort

learner = SequenceLearner(length; sequence=["a", "bb", "ccc"], value_type=Int)
BlockingRunner(learner; batch_size=2)

data = result(learner)     # (indices, values) of the told elements
data.values                # [1, 2, 3]

examples/sequence.jl is the runnable script.

Algorithm

There is nothing adaptive: ask returns the lowest indices that are neither told nor pending. The loss is the fraction of elements not told yet, so done(learner) (without tol) means that every element is told, and a runner without tol stops then. result works at any time and returns the told elements only, in index order. value_type (default Any) sets the element type of the stored values; use a concrete type for a concretely typed result.

Limits

Telling an index again is ignored. Differences to upstream: Deviations.

API

AdaptivePort.SequenceLearner — Type
SequenceLearner(f; sequence, value_type = Any)

Evaluate f(element) for every element of sequence, in order. Use it to run a plain map through the runners. The points the learner asks for are (index, element) with a 1-based index, and learner.f is the wrapper (index, element) -> f(element) that runners call. Port of upstream's SequenceLearner.

The loss is the fraction of elements not told yet, and done(learner) means every element is told.

Type Parameters

  • V: type of the values, from value_type. The default Any accepts everything; pass a concrete type, e.g. value_type = Float64, for typed storage and a concretely typed result.

Keyword Arguments

  • sequence: the elements; copied.
  • value_type: values are converted to this type when told.
