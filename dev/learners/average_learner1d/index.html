AverageLearner1D

AverageLearner1D learns a noisy scalar function on an interval. It decides between two things: sample a new $x$, or draw more samples at an existing $x$. Points are tuples (seed, x) and the function is called as f(seed, x); it must return one sample whose randomness comes from seed only.

using AdaptivePort, Random

noisy(seed, x) = tanh(10x) + (0.05 + 0.2 * (x > 0)) * randn(Random.Xoshiro(hash((seed, x))))
learner = AverageLearner1D(noisy; bounds=(-1, 1), min_samples=10)
BlockingRunner(learner; max_npoints=40)   # counts distinct x, not samples

r = result(learner)    # (x, y, error, nsamples), sorted by x
nsamples(learner)      # all samples; npoints(learner) counts distinct x

examples/average_learner1d.jl prints how the samples spread: the noisy right half gets far more samples than the quiet left half.

The seed must be the only source of randomness

f(seed, x) must be reproducible for the same (seed, x). Seed a local generator from both (as above, Random.Xoshiro(hash((seed, x)))), never the global RNG; otherwise the error bars are wrong.

Two kinds of point counts

npoints(learner) counts distinct x, so max_npoints limits the number of $x$ values, not of samples. nsamples(learner) counts all samples.

Advanced: algorithm

An inner Learner1D holds the sample means and chooses where a new $x$ goes, with the usual interval loss. Each $x$ also has an error: the half-width of the confidence interval of its mean, using Student's $t$ quantile at level $1 - \alpha$ (alpha), so the true value lies in $\bar y \pm \text{error}$ with probability $1 - 2\alpha$. It is Inf with one sample.

ask(l, n) proposes all $n$ points at one $x$:

  1. If some $x$ is undersampled (fewer than min_samples samples, or fewer than neighbor_sampling times the mean sample count of its neighbours) it gets $n$ more seeds.
  2. With at most one $x$ told, a new $x$ is proposed.
  3. Otherwise the $x$ with the largest rescaled error (its error over the smaller adjacent segment length of the means) is resampled if that exceeds delta; else a new $x$ is chosen by the Learner1D rule on the means.

An $x$ with error <= min_error or max_samples samples is not resampled by rule 3. ask never modifies the learner itself; pending points are registered through tell_pending!. The loss is the loss of the means; loss(learner; real = false) lets pending $x$ split their interval.

Limits

Resampling cost is a linear scan over the $x$ per ask. max_samples is not enforced when ask(l, n) is called with $n > 1$ (as upstream). Differences to upstream: Deviations.

API

AdaptivePort.AverageLearner1D — Type
AverageLearner1D{T, F, I}

Adaptive sampler of a noisy scalar function on an interval: it decides between sampling a new x and drawing more samples at an existing x. Port of upstream AverageLearner1D.

A point is a tuple (seed, x), the runner calls f(seed, x), and f must return one noisy sample that depends on seed only through its randomness. Samples with the same seed at the same x are the same sample, so a repeated one is ignored.

Sampling rule. ask proposes all n points at one x, because n is normally much smaller than min_samples. If some point is undersampled (the smallest such x; upstream picks an arbitrary one) it gets n more seeds, continuing after the samples told so far. With at most one told x, a new x is proposed. Otherwise the x with the largest rescaled error (its error over the smaller adjacent segment length) is resampled if that exceeds delta, and else a new x is chosen by the Learner1D rule on the means. ask never changes the learner itself; with tell_pending = true the points are registered with tell_pending!.

An inner Learner1D holds the sample means and decides where to put a new x; its stored mean is moved with the unexported update_value! whenever a sample arrives. The y-scale of the inner learner is widened by every individual sample, not only by the means, as upstream.

Fields: f, inner (the Learner1D of means), samples (x => (seed => y)), undersampled (points with fewer than min_samples samples, or fewer than neighbor_sampling times the mean count of their neighbors), error (half-width of the confidence interval of the mean at each x, Inf with one sample), pending (issued (seed, x) not yet told) and the settings delta, alpha, neighbor_sampling, min_samples, max_samples, min_error.

Type Parameters

  • T<:AbstractFloat: type of x and of the sample values.
  • I<:Learner1D: the inner learner.

Construct with AverageLearner1D(f; bounds).
